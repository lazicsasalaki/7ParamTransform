# 7-Param Helmert Transform QGIS Plugin

Least squares 7-parameter Helmert transformation with:
- Error ellipses (95% confidence, scaled x5 for visibility)
- Baarda data snooping for outlier detection
- Residual visualization layers

## How to use
1. Install plugin from QGIS Plugin Manager (once published)
2. Prepare points.txt file with format: ID X1 Y1 Z1 X2 Y2 Z2
3. Run plugin → Browse file → RUN
